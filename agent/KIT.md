# Agent Kit Specification

- Kit Version: 5.1 (Enterprise Multi-Agent Edition - Refined)
- Architecture: Supervisor-Worker with Strictly Typed Contract Handoff
- Paradigms: Contract-First, Test-Driven Development (TDD), Context Isolation, Zero-Hallucination, Anti-Looping
- Supported Environments: Universal (Go, Python, TypeScript, Rust, C#, Docker, etc.)
- Enhancements in 5.1: Enforced retry limits, strict validation gates, and enhanced DEV/QA segregation.
