# Masters Overview Directory

This directory contains high-level architectural overview documents and cross-cutting concerns that span multiple Masters.

## Purpose
- Store cross-domain architecture diagrams and decision records that are too broad for a single Master file.
- Capture system-wide constraints (e.g. authentication strategy, shared data models, rate limiting policies).
- Provide a "30,000-foot view" of the full project roadmap for onboarding new agents or operators.

## Usage
When planning a new Master, check this directory first for existing cross-cutting decisions that your new Master must respect.
