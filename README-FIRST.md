# راهنمای شروع سریع — Agent Kit v5.1 (Multi-Agent Architecture)

این پکیج کامل‌ترین و استانداردترین فریم‌ورک مهندسی نرم‌افزار برای هدایت ایجنت‌های هوش مصنوعی (مانند Claude Code، Cursor، و CLI Agentها) بر پایه الگوهای Orchestrator-Worker، TDD و توسعه قراردادمحور (Contract-First) است. در نسخه ۵.۱ تمامی حفره‌های مربوط به گم شدن کانتکست و لوپ‌های تکراری برطرف شده است.

## محتویات بسته:
- `README.md`: ریدمی انگلیسی مخصوص گیت‌هاب با فلوچارت معماری.
- `AGENTS.md`: نقطه ورود اصلی ایجنت‌ها.
- `BOOTSTRAP.md`: پرامپت جامع راه‌اندازی و شناسایی خودکار استک.
- پوشه `agent/`:
  - `rules/`: قوانین غیرقابل نقض (ایمنی، کیفیت، گیت، تست، امنیت و پروتکل چند ایجنتی).
  - `roles/`: تعاریف نقش‌های ایزوله (Orchestrator، Architect، Developer، QA، DevOps، Security Reviewer).
  - `skills/`: روندهای تکرارپذیر مهندسی.
  - `masters/`: پرامپت‌های برنامه‌ریزی دامنه‌محور و اجرای ارکستراتور (`EXECUTE.md`).
  - `Milestones/`: محل نگهداری تسک‌های شکسته شده.
  - `tools/`: ابزارهای ساخت فیچر، ساخت اسکیل و تسک سریع.
  - `HANDOFF_SCHEMA.md` و `.state/handoff.json`: قرارداد تبادل وضعیت قطعی بین ایجنت‌ها.
  - `MULTI_AGENT_COMMANDS.md`: فرامین آماده برای کپی‌پیست در ترمینال.
  - `RUNBOOK.md`: دفترچه جامع راهنمای اجرا.

## ۳ قدم اول برای شروع:
1. پوشه `agent` و فایل‌های روت (`AGENTS.md` و `BOOTSTRAP.md`) را در ریشه مخزن پروژه قرار دهید.
2. بخش «PROJECT BRIEF» را در فایل `BOOTSTRAP.md` پر کنید (اگر چیزی نمی‌دانید خالی بگذارید).
3. دستور زیر را به ایجنت بدهید:
   `Read BOOTSTRAP.md and follow it exactly.`
4. پس از اتمام، از دستورات فایل `agent/MULTI_AGENT_COMMANDS.md` استفاده کنید.
